# BCalm-Analysis-Workflow-for-MPRA-NCCM-Data
This is a script to run the BCalm R package developed by the Kircher Lab. It performs activity analysis, wt-mut differential activity analysis, and visualizations

## Project Overview

This repository contains R scripts for processing, analyzing, and visualizing Massively Parallel Reporter Assay (MPRA) data using BCalm.

The primary objective is to quantify differences in regulatory activity between WT and MUT sequences and identify candidate mutations associated with altered transcriptional activity.


## Input Data

The scripts require appropriately formatted MPRA sequencing data and associated experimental metadata.

Input files are not  included in this repository. Users should ensure that their input data conform to the expected formats and that experimental labels, sample identifiers, and replicate assignments are consistent with those specified in the scripts.
